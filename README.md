Blade Runner 2D Game

Features as of the World Update:

- Blocks breaking & placing
- World saving & loading
- Good world generation with 11 biomes
- Somewhat good GUI system

Controls:

- WASD - move the player
- R - regenerate the world
- 1 - save the world
- 2 - load the world
- F3 - open / close the debug menu
- ` (backtick) - open / close the console
- Left mouse button when hovering over inventory slot - take or place back the item
